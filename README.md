# BOXMUSIC 🎵

> Ứng dụng web nghe nhạc cá nhân hóa chuẩn **UI-UX Pro Max** với kiến trúc đa nền tảng mượt mà (Desktop 3-Panel Pro & Mobile Native App).

---

## 🌟 Tính Năng Nổi Bật

### 💻 Màn Hình Máy Tính (Desktop Pro 3-Panel)
- **Left Sidebar**: Điều hướng thông minh, danh sách Playlist cá nhân, shortcut bài hát đã thích, bộ chuyển đổi Theme Neon 1 chạm.
- **Center Stage**: Grand Hero Banner phong cách cinematic, thanh lọc thể loại/tâm trạng (Mood Chips), Daily Mixes, Bảng xếp hạng Top bài hát với thời lượng và lượt nghe.
- **Right Sidebar (Now Playing & Live Lyrics & Queue)**: Đĩa than Vinyl xoay êm ái, Lời bài hát Karaoke live đồng bộ theo giây (bấm câu bất kỳ để tua nhạc), Hàng đợi phát tiếp theo.
- **Bottom Full-Width Player Bar**: Thanh điều khiển phát nhạc toàn màn hình, Seekbar mượt mà, bộ chọn chất lượng âm thanh (**Lossless Hi-Res 24-bit 96kHz / 320kbps**), Hẹn giờ tắt nhạc (Sleep Timer), Volume slider.

### 📱 Màn Hình Di Động (Mobile Native App)
- **Header Mobile**: Lời chào theo thời gian thực (*Chào buổi sáng/chiều/tối*), Avatar cá nhân, VIP badge.
- **Thanh Điều Hướng Dưới (Bottom Nav Bar)**: Cố định với hiệu ứng neon pill phát sáng.
- **Mini Player Nổi**: Cố định trên Bottom Nav, hiển thị thumbnail, tên bài hát và điều khiển nhanh.
- **Full Screen Player**: Trình phát toàn màn hình với đĩa than xoay, lời bài hát karaoke và danh sách chờ.

## 🛠️ Công Nghệ Sử Dụng (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Glassmorphism, Custom Animations
- **Animations**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **Audio Engine**: HTML5 Audio / Web Audio API với bộ đếm thời gian và âm thanh Lossless

## 🚀 Hướng Dẫn Cài Đặt & Chạy

### 1. Cài đặt dependencies
```bash
npm install
```

### 2. Chạy môi trường phát triển (Dev)
```bash
npm run dev
```

### 3. Đóng gói cho Production
```bash
npm run build
npm run preview
```
